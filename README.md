# Ayla — código para publicação

Cópia sem dados locais, memórias, conversas, credenciais e prompts personalizados. Os textos de instrução foram esvaziados; configure seus próprios prompts antes de usar.

Instale as dependências de `requirements.txt` e copie `.env.example` para `.env`, preenchendo suas próprias configurações. Imagens, mídias, bancos e configurações pessoais não estão incluídos. Algumas funções exigem esses recursos locais.

Publique somente o conteúdo desta pasta. Não copie a pasta original nem seu histórico Git.

Inclui MODOS (essenciais, adicionais e contínuos), módulos complexos e a pasta de suporte para VPS/Host (`ayla_host/`). Prompts desses módulos também foram removidos. Configure modelos, vozes e serviços antes de usar. Ícones, sprites e coleções pessoais de imagens não foram copiados; recursos visuais opcionais podem precisar de substitutos.
